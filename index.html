LinRufus

Create bootable USB drives from any ISO — including Windows 10/11 — directly from your Linux terminal. Zero GUI, maximum efficiency.

Installation
# Download & Install
wget github.com/ishan3299/linrufus/releases/latest
sudo dpkg -i linrufus_*.deb
Usage
# List USB devices
sudo linrufus --list

# Write Windows/Linux ISO
sudo linrufus --device /dev/sdc --image ./Win11.iso
