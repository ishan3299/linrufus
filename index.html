LinRufus

The Linux Port of the Popular Rufus Utility

What is LinRufus?

LinRufus is a Linux-native CLI tool created to bring the reliability and features of Rufus to the Linux ecosystem. It allows you to create bootable USB drives from ISO images with ease, including full support for **Windows 10/11 ISOs** (splitting large WIM files automatically) and standard Linux Hybrid ISOs.

Features

  • Cli-Native: Fast and scriptable.
  • Windows Support: Automatically handles split-WIM for Windows 10/11 UEFI boot.
  • Safety: Built-in safety checks to protect your data.
  • Debian Ready: Easy installation via `.deb`.

Installation

wget https://github.com/ishan3299/linrufus/releases/download/v0.1.1/linrufus_0.1.1-1_amd64.deb
sudo dpkg -i linrufus_0.1.1-1_amd64.deb

Usage

# List devices
sudo linrufus --list

# Write an ISO (Linux or Windows)
sudo linrufus --device /dev/sdX --image /path/to/image.iso
