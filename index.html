LinRufus

Create bootable USB drives from any ISO — including Windows 10/11 — directly from your Linux terminal.

⬇️ Download 📂 Source
🪟Windows ISO
⚡WIM Split
🛡️Safe Mode
📦Debian .deb
Install
# Download & Install
wget github.com/.../linrufus.deb
sudo dpkg -i linrufus.deb
Usage
# List devices
sudo linrufus --list

# Write ISO
sudo linrufus -d /dev/sdc -i Win11.iso
