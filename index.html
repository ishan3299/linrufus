LinRufus

Create bootable USB drives from any ISO — including Windows 10/11 — directly from your Linux terminal.

⬇️ Download .deb 📂 View Source
🪟

Windows ISO Support

Automatically splits large install.wim files using wimlib for perfect UEFI compatibility on FAT32.

🚀

Fast & Efficient

Uses rsync for intelligent file copying with no unnecessary overhead.

🛡️

Safety First

Built-in device verification and confirmation prompts to prevent accidental data loss.

📦

Debian Ready

Install with a single dpkg command. No complex dependencies.

Quick Start

Installation
# Download the latest release
wget https://github.com/ishan3299/linrufus/releases/latest/download/linrufus.deb

# Install
sudo dpkg -i linrufus.deb
Usage
# List available USB devices
sudo linrufus --list

# Write an ISO to a device
sudo linrufus --device /dev/sdX --image ./Win11.iso
